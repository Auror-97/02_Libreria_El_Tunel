# **EL TUNEL-SITIO WEB LIBRERIA**
Proyecto académico de desarrollo web enfocado en la creación y maquetación de una interfaz
para una libreria en linea, usando HTML  y CSS.
## **Descripción**
La página incluye diferentes elementos orientados a presentar y
organizar el contenido de la librería,tales como barra de navegación, buscador,
catálogo de libros recomendaciones y un pie de pagina.

## **Objetivo del proyecto**
El fin de este proyecto fue practicar los fundamentos del desarrollo
web mediante la construcción de una interfaz, aplicando conocimientos
de estructuración con HTML, diseño y distribución de elementos con CSS.

Fue desarrollado como parte de mi formación en desarrollo web.

## **Elementos desarrollados** 
- Estructuración del contenido mediante HTML.
- Estilos personalizados con CSS.
- Implementación de layouts utilizando Flexbox y CSS Grid.
- Buscador.
- Catálogo de libros.
- Sección de recomendaciones.
- Pie de página.
